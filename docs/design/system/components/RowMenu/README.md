The ⋮ menu: a glass popover with a tail pointing at its ⋮ button. It holds every action that is not the one primary button.

- Header ⋮: the list's own tools (Scan passport, Search, Export, Print) and always **Select…** last.
- Row ⋮: Edit, Access, Punch link, Archive…; **Delete** last, in red-soft, under a hairline.
- Items 14px/500, icon 17px in ink-on-glass; hover shows a 3px gradient line on the left.
- Opens 10px under the button, right-aligned; the tail (`--tail`) sits under the button's center.
- A tap outside closes it; opening another menu closes the open one.
