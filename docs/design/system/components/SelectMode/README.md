Select mode for every list: entered from the header ⋮ → Select…, it adds drawn-tick boxes to the plates and a glass action bar at the bottom.

- Add `og-select` to the list: a 24px tick box slides in left of each avatar; row ⋮ and swipe turn off.
- Tap a plate toggles it (`og-plate.on`, fill `plate-on`, the check draws itself).
- Above the list: "N selected" and **Select all** (toggles all / none).
- Bottom bar (`og-bar`): count, the list's bulk actions as icon buttons, **Delete** (danger), ✕ to leave.
- Bulk delete collapses the plates and shows "N workers deleted · Undo".
- Every list that has bulk sense gets it: workers, clients, suppliers, users, firms, punches, pending hours, documents.
