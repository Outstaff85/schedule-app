Hours approval: the shared screen used by the client portal, the supplier portal's Approvals tab and an HR in Accounting.

- Month arrows (no future months) and tabs **Hours / Schedule**, each shown only with its tick.
- Figures: approved, waiting, disputed or changed, fixes proposed. Below them a status bar ("N of M days approved") with Export, Select and the one primary **Approve the month**.
- A section line per worker, a plate per day with a status pill (Waiting, Approved, Fix accepted, Changed after approval, Disputed, Fix proposed, Fix rejected) and three actions: ✓ approve, ⚠ dispute, ✎ propose a fix.
- Select plus the glass bar approves many days at once; dispute and fix open in a sheet.
