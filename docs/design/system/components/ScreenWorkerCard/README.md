The worker card: a read-only bottom sheet.

- Head: big avatar in the plate's color, full name, "site · today's punch", the month's hours, and every notice chip.
- Three small status pills (Active / Vacation / Inactive) save at once; under them the date the Form 101 was saved.
- An **Info / Docs / Hours** switch: Info has phone, start date, ID, address, income types, clients, supplier and notes in pairs; Docs lists contract, visa, work permit and other documents with Renew or Upload; Hours shows the month and the latest hours batch with its status.
- Bottom: one primary **Edit** and a ⋮ with Pay, Add document, Download, Upload hours and the rest.
- It closes with a tap on the backdrop or a swipe down; it has no close button.
