The Admin tab: it opens with no section; a text tab bar picks one.

- **Punch Log** (all who see the tab): figures Total IN, Total OUT, Today, Total; Log / By Client switch; filters Worker, Client, Date, Type; a punch plate with IN (green) or OUT (red), name, date, site, GPS distance and time. Tap edits; ⋮ and swipe give Edit and Delete with Undo. Export CSV, Clear Log (month checklist, type DELETE) and "Load earlier month" are on the bar.
- **Firms, Users** (owner, super-admin): firm plates with workers and clients counts; user plates with a role pill and ticks (Hours, Approve, Export…); the glass Create firm and New user buttons.
- **Errors, Timings** (super-admin only).
- An HR login never sees Admin.
